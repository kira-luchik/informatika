# Мои развлекалки

- `index.html` — главная страница со ссылками
- `tests/` — Тестотека (15 тестов)
- `tarot/` — Три карты Таро
- `CNAME` — сюда вписывается твой домен

## Как выложить на GitHub Pages со своим доменом

### 1. Загрузи файлы
1. Зайди на github.com → кнопка **New** (новый репозиторий).
2. Название любое, например `fun-site`. Тип **Public**. Нажми **Create repository**.
3. На странице репозитория нажми **uploading an existing file**.
4. Перетащи туда **содержимое** распакованной папки (файлы `index.html`, `CNAME`, `README.md` и папки `tests`, `tarot`), а не саму папку целиком.
5. Нажми **Commit changes**.

### 2. Впиши свой домен
1. Открой файл `CNAME` в репозитории → значок карандаша.
2. Сотри `example.ru` и впиши свой домен, например `mysite.ru` (без `https://` и без `/`).
3. **Commit changes**.

### 3. Включи Pages
1. **Settings** → слева **Pages**.
2. В **Source** выбери **Deploy from a branch**, ветка **main**, папка **/ (root)** → **Save**.
3. В поле **Custom domain** должен появиться твой домен (если нет — впиши и нажми Save).

### 4. Настрой DNS у регистратора домена
Там, где ты покупала домен (Reg.ru, Timeweb, Beget и т.п.), открой управление DNS и добавь записи.

Для домена вида `mysite.ru` — четыре записи типа **A** (имя `@`):
```
185.199.108.153
185.199.109.153
185.199.110.153
185.199.111.153
```
И одну запись **CNAME** для `www` → `твой-логин.github.io`

Если хочешь поддомен (например `fun.mysite.ru`) — достаточно одной записи **CNAME**: имя `fun` → `твой-логин.github.io`.

Старые A-записи для `@` (если были) лучше удалить.

### 5. Подожди и включи HTTPS
DNS обновляется от 15 минут до суток. Когда в **Settings → Pages** появится зелёная галочка, поставь **Enforce HTTPS**.

Пока домен не заработал, сайт уже открывается по адресу `https://твой-логин.github.io/fun-site/`.
